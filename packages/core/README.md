# @journeygap/core

JourneyGap core, an Apache-2.0 component for consent-gated application journey observation and local analysis. Node.js 24+ is required for server/CLI packages.

Pre-release: names are provisional. See the [repository documentation](https://github.com/ysj101/jorney_gap#readme) for configuration, consent, privacy, installation and operational boundaries. No npm publication has been authorized yet.

Dependencies retain their own licenses. This package ships compiled modules without vendoring or bundling dependency source. Preserve dependency license/notice files when redistributing or bundling. See [license policy](https://github.com/ysj101/jorney_gap/blob/main/docs/licenses.md).
